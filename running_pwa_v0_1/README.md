# RUN PWA Ver.0.1

自分用ランニングPWAの最初のバージョンです。

## 実装済み

- フリーラン
- 距離目標（0.1 km単位）
- 時間目標（1分単位）
- GPSによる走行距離
- 経過時間
- 現在ペース（直近約30秒を平滑化）
- 平均ペース
- 一時停止 / 再開
- 終了結果
- 端末内への履歴保存（localStorage）
- 今週 / 今月の総距離
- PWA用 manifest / service worker

## 注意点

### GPS
位置情報APIは通常、HTTPS環境か localhost でのみ使用できます。
PC上で index.html を直接開くだけではGPSが動かない場合があります。

### iPhone
SafariでHTTPS配信されたページを開き、
共有 → ホーム画面に追加
でPWAとして使えます。

### バックグラウンド
iPhoneの画面をロックした状態でのGPS計測は、Web/PWAでは制限があります。
本格的なバックグラウンド計測が必要になったら、将来的にネイティブアプリ化を検討します。
